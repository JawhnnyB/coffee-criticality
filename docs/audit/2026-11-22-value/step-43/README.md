# Step 43

Night Shift Endless is on the dawn lot, after the rotation.

It starts at night 5. Each night after that adds an event and shortens the time to a trip, down to 0.45, with one pot. A passing dawn offers Stay. A trip, a relief, or a D or F ends it.

The high score is nights stood and the best grade points. It lives in cc.endless, not the week save. The run is a replay, so Elena's trust and the night flags do not move.

The unit test is `scripts/endless.test.mjs`. The click proof is in result.txt: the lot opens night 5, and the week save has no night:5.
