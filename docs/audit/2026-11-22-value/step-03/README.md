# Step 3: the menu names the save

Under Continue, the menu says when the save was written and where it is. The clock is the wall clock. A day shift says the day. A night rotation says the night. Dawn says dawn.

`scripts/save-note.mjs` saved three shifts, reloaded each tab, and read the line:

- Saved 11:53, Day 1
- Saved 11:53, Night 2
- Saved 11:53, Dawn
