# Step 38

Night pace is a setting, saved in cc.settings, not in the week.

Relaxed multiplies escalation by 1.35, adds one pot, and drains coffee at 0.7. Nuke multiplies escalation by 0.72, takes one pot (never the last), and drains at 1.4. Standard is the night as dealt before. The choice is applied when the night is dealt.

The buttons fill the same way text size does. The unit test is `scripts/night-pace.test.mjs`. The click proof is in result.txt.
