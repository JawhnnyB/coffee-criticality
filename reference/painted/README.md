# Painted reference art

Nothing in this folder ships with the game, and no source file loads it.

These are the painted pictures from earlier passes: the plate originals that
`tools/artkit/pixelize.py` redrew onto the pixel grid, the old menu video and its
poster, and the stills under `stills/` that the game stopped using. Keep them as
reference for drawing the official art. Do not link to them from `src/`.

The game loads one painted still: `public/art/gen/stills/cutaway_pwr_loop.jpg`.
