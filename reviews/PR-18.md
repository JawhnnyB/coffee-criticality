## Findings

Blocking (request-changes):

1. **Canvas text.** `src/game/ReactorApps.tsx` 147–148: `g.font = "8px monospace"` and `g.fillText(String(health), 126, 18)` draw the core health number on the CORE CAM canvas. The brief says no text on the canvas. The same number is already in HTML at line 106, so delete the `fillText`. The "60" in `docs/audit/2026-11-08-m2-canvas-rod.png` and `-wide-cam-pwr.png` is this text.
2. **Off-list colours in the CORE CAM and Core Map UI.** None of these are in STYLE-STANDARD §3–5 or the GROK_PHASES 2.2 palette:
   - `ReactorApps.tsx` 132: `#2a241c` (inner screen fill).
   - `ReactorApps.tsx` 206: `#8a8070` (PWR/MSR chevrons).
   - `ReactorApps.tsx` 94: `#5c4636` (caption text).
   - `ReactorApps.tsx` 287: `#5c4636` (Results trend axis text).
   - `ReactorApps.tsx` 346: `#3b2318` (Core Map cell border).
   `#3b2318` also appears in PR #8, which I approved. It is still not in the standard, so either the owner adds it to §3–5 or it goes here too. Use listed tokens in this PR (`#1c1410` screen, `#16110d` ink, `#f3e6d0` cream, `#4e5560` graphite, `#3d5c66` steel) unless the owner adds the colour.
3. **Colour-safe ramp is a new palette.** `src/game/schematicMath.ts` 8: `SAFE_BANDS = ["#2a241c", "#3e382c", "#5c5344", "#7a6e5c", "#a89880", "#d2c4ae", "#f3e6d0"]`. Only `#f3e6d0` is a listed token. The other six are not in the standard, and the brief says "do not invent a new palette." The colour-safe mode also needs to keep the seven flat bands and add a non-colour cue (the tick pattern in `PixelSchematic.tsx` `scaleBar` is a good start). It should not swap in a grey ramp. The test at `scripts/reactor-readout.test.mjs` 87–94 asserts the grey ramp, so it changes with the fix.
4. **Rod is not §6.1.** `ReactorApps.tsx` 151–160: a steel box, a screen box, seven glow blocks, and a 2px centre line. No cladding, no gap, no pellet split. This is geometry gap 1.
5. **Assembly is not §6.1.** `ReactorApps.tsx` 162–186: a plain grid of cells. No spacers, no guide tubes. This is geometry gap 2. The screenshot `2026-11-08-m2-canvas-assembly.png` shows the same thing.
6. **Pebbles are squares, not packed circles.** `ReactorApps.tsx` 188–202: `fillRect` squares of radius `r`. No helium colour between them (`#d4cce6` in STYLE-STANDARD §4 is not used). This is geometry gap 3. The screenshot `2026-11-08-m2-wide-cam-pebble.png` shows squares.
7. **BWR vapour does not rise.** `ReactorApps.tsx` 139–143: `Math.round(voidFrac * 8)` fixed 2×2 squares in one row at fixed y. They do not move and do not show a rate. The HTML label "Boiling proxy 0.xx" at line 107 is present, which is fine. The rising vapour bubbles in §6.1 are not drawn. This is part of geometry gap 4.
8. **PWR and MSR flow direction is not an arrow.** `ReactorApps.tsx` 138 and 204–215: a 2×2 dot with a 4×1 bar, four of them. Two sit inside the lattice (x = 78, y = 38–58). §4 says every pipe has direction arrows, and the chevrons do not read as arrows. Flow reads only from the moving dots. This is part of geometry gap 4. I checked the MSR case in code only.
9. **No integer scale on resize.** `ReactorApps.tsx` 98–104: a 160×96 canvas is fixed at 320×192 CSS px. Nothing scales to an integer on resize, and the scene is not centred. §6.4 requires both. This is geometry gap 5.

Not blocking, but record them:

10. **Trend text under 12px.** `ReactorApps.tsx` 284 and 287: SVG text at `fontSize="8"`. This is not canvas text, but the 12px label rule covers it. Fix in the finish PR.
11. **Core Map is not tied to the run.** `ReactorApps.tsx` 297–302: the grid is local `useState`, so it resets each time the window opens. `choose` stores `shuffleBest` only (321–322), and `shuffleDone` is not set. The rule is intact. The map does not persist. This is a known teaching shortcut; record it for the owner.
12. **Tests do not cover the drawing.** `scripts/reactor-readout.test.mjs`: there is no per-type canvas snapshot (§6.5). The fullCore test is `cellCount` numbers (75–76), not a drawing count. Reduced motion is tested on `particleCount` only (73–74), not on the `stepFlow` path used by `CoreCamApp`. Monotone mapping is tested on one plant (PWR) only. This is the fourth gap, with the walkthrough.
13. **Checked and fine.** Reduced motion stops the flow and updates glow only past 5% (`ReactorApps.tsx` 65, 69–70). Scram eases to 0.15 over about 3 s and back over about 6 s (`reactorReadout.ts` 218–226). Health weights are 40/20/20/20 (`reactorReadout.ts` 83–86). Glow stops are listed tokens with no red (`reactorReadout.ts` 193–198). The default-design message is present (`ReactorApps.tsx` 97). `drawCam` skips when `offsetParent` is null (60), so the minimized case is covered.
